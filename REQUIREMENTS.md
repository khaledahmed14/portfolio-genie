# Requirements Gathering - Venom AI

## 1. Stakeholder Analysis

- **Primary Users:** Software developers, computer science students (DEPI trainees), and freelancers looking to showcase their GitHub projects effortlessly.
- **Evaluators / Lecturers:** DEPI supervisors assessing project architecture, code quality, and documentation.

## 2. User Stories & Use Cases

- **As a developer**, I want to sign in and link my GitHub account so that my repositories are automatically imported.
- **As a user**, I want to customize my portfolio theme and preview the layout before publishing.
- **As a recruiter**, I want to view clean, structured developer portfolios with direct links to live demos and source code.

## 3. Functional Requirements

- User authentication workflow (Sign In / Register / Demo mode).
- Interactive dashboard and customization wizard.
- Real-time preview of the generated portfolio.
- Seamless GitHub integration and deployment options.

## 4. Non-Functional Requirements

- **Usability:** Intuitive dark-mode UI with high-contrast sapphire/cyan accents.
- **Security:** Secure client-side routing and token handling.
- **Performance:** Fast rendering speeds using Vite and React.
